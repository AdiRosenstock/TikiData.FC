# ⚽📊 TikiData FC

Data-driven football analytics project focused on analyzing the game through statistics and transforming insights into clean, engaging visualizations.

---

## 🚀 About the Project

TikiData FC combines **football + data science** to explain performance, trends, and hidden insights in a simple and visual way.

The goal is to:
- break down complex stats (xG, performance metrics)
- highlight underrated patterns and players
- present data in a way that is easy to understand and visually appealing

---

## 📊 What We Do

This project focuses on analyses such as:
- Goals vs Expected Goals (xG)
- Player performance trends
- Over/underperformance
- Hidden statistical insights across leagues

Each analysis is:
- built using Python (pandas, matplotlib)
- visualized for social media
- organized into its own folder in this repository
